# Privacy Policy – n8n course WhatsApp test app

Last updated: 26 November 2026

This app is a personal learning project by Rajasekhara Lankela, used to test
WhatsApp messaging with an n8n automation workflow.

**What we collect:** the phone number and message text of people who message
the test WhatsApp number.

**How we use it:** only to generate an automated reply during testing.
Messages may be processed by OpenAI to create the reply.

**Sharing:** data is not sold or shared with anyone else.

**Retention:** test data is kept only as long as needed for testing and is
deleted afterwards.
